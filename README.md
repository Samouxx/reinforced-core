# Reinforced Core (26.x port)

> **Unofficial port to Minecraft 26.3 (Fabric).**
> This is a modified version of [Reinforced Core](https://github.com/Aton-Kish/reinforced-core) by **Aton-Kish**,
> ported by **Samouxx** in November 2026. The original library stopped at Minecraft 1.21.11.
> It is bundled inside the [Reinforced Chests 26.x port](https://github.com/Samouxx/reinforced-chests):
> players do not need to install it separately.
> Please report problems with this port [here](https://github.com/Samouxx/reinforced-core/issues), not to the original author.
>
> Changes from the original 4.0.9:
> - code translated from Yarn names to Mojang names (checked: the compiled classes were identical to the original on 1.21.11);
> - ported to Minecraft 26.3: storage screen drawing, creative tab, Mod Menu config screen;
> - the automated test system (gametest) was removed: it relied on a part of the game that 26.x rewrote.
>
> To build Reinforced Chests, first run `gradlew publishToMavenLocal` here.
>
